# Glossary

- **Admin**: A user with administrative privileges (Role = `ADMIN`), capable of managing system settings and moderation.
- **Checkmate**: A win condition where the player's king is in check and has no legal moves to escape.
- **Draw Offer**: A proposal by one player to end the game in a draw (TTL 30s).
- **FEN (Forsyth–Edwards Notation)**: Standard notation for describing a chess board position.
- **Guest**: A temporary user account/session for unauthenticated visitors. Backend identifies them with `guest_{random8}` and a `guestToken`. Frontend uses fallback authentication to create and store this token.
- **Host (Room Owner)**: The creator of a room who can change settings or start the game. If they leave, the role is transferred randomly.
- **Increment**: Time added to a player's clock after making a move.
- **JTI (JWT ID)**: Identifier used for refresh tokens stored in Redis.
- **JWT**: JSON Web Token used for stateless access verification.
- **Orphan Image**: An image uploaded to Cloudinary but not yet attached to a published post. Cleaned up automatically after 1 hour.
- **PGN (Portable Game Notation)**: Plain text format for recording chess games. Generated by backend upon game end.
- **Player**: A user occupying a playing seat (White or Black) in a room.
- **Presence**: The system of tracking online users via WebSocket connections. Tracked via Redis.
- **Room**: A real-time session instance for playing games or discussions.
- **Session**: A specific WebSocket connection instance. A single user can have multiple concurrent sessions.
- **Single-Flight Guard**: A frontend programming pattern used during token refreshing to prevent multiple identical requests simultaneously.
- **Soft Delete**: Marking a record as deleted (`deleted_at` or `isActive = false`) rather than physically removing it. Applies to Users, Posts, Comments, and Likes.
- **Spectator**: A user inside a room who is not participating in the game. Can observe and chat (unless locked).
- **STOMP**: Simple Text Oriented Messaging Protocol used over SockJS for real-time WebSocket communication on the frontend.
- **Tiptap**: The rich-text editor framework used on the frontend. Backend expects its specific JSON node structure.
- **Time Control**: Time limits for a game, composed of total time and increment.
- **UCI (Universal Chess Interface)**: Standard string format representing a chess move.
- **User (Registered User)**: A fully authenticated and registered user.
