# Screens

Here is an overview of the screens in the React application. Detail documentation for each can be found in the `screens/` directory.

- **Landing Page** (`/` or `/landing`): Initial view for non-authenticated users.
- **Dashboard** (`/` or `/dashboard`): The main hub for authenticated and guest users.
- **Login Page** (`/login`): User authentication screen.
- **Register Page** (`/register`): User sign-up screen.
- **Profile Page** (`/profile`): Screen for registered users to view and edit their profile.
- **Notifications Page** (`/notifications`): View recent notifications and alerts.
- **Room Page** (`/room/:roomId`): Real-time collaborative/game room.
- **Forum Pages** (`/forum`, `/forum/create`, `/forum/my-posts`, `/forum/posts/:id`): Discussion boards.
- **Learn Pages** (`/learn`, `/learn/:lessonId`, `/learn/play-bot`): Educational content and bot-play.
- **Error Pages** (`/403`, `/404`): Forbidden access and Not Found screens.
