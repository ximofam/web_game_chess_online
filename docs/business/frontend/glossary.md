# Glossary

- **Guest**: An unauthenticated user playing or testing the application on a temporary session.
- **Registered User (User)**: A fully authenticated user with a saved profile.
- **Room**: A real-time session instance (e.g. for games or discussions) identifiable by a `roomId`.
- **STOMP**: The simple text-oriented messaging protocol used over SockJS for real-time WebSocket communication.
- **Single-Flight Guard**: A programming pattern used in token refreshing to prevent multiple identical asynchronous requests from being fired simultaneously.
